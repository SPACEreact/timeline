# Visual timeline

An immersive, full-screen journey from the Big Bang to the present. Drag the timeline to move through 21 cinematic image chapters.

Live site: https://visual-timeline-himanshu.droidbais.chatgpt.site

The site is static and served from `dist/`. Open `dist/index.html` locally or serve that directory with any static HTTP server. After the present, the experience runs a 30-minute randomized visual sequence built from the existing images; it does not call an image-generation API.
