# Visual timeline

An immersive, full-screen journey from the Big Bang to the present. Drag the timeline to move through 21 cinematic image chapters. After the present, explore a randomized 30-minute pool of 12 distinct visuals: the earlier Crab Nebula and magnetar images plus 10 new quantum, cellular, space, exoplanet, and interstellar-future scenes.

Live site: https://visual-timeline-himanshu.droidbais.chatgpt.site

The site is static and served from `dist/`. Open `dist/index.html` locally or serve that directory with any static HTTP server. After the present, the experience runs a 30-minute randomized visual sequence built from the chapter images and the extended post-present pool; it does not call an image-generation API.
